# Monorepo layout: backend/, frontend/, packages/

Phase 2 adds a React dashboard alongside the existing FastAPI backend and the `packages/playwright-reporter` npm package. Rather than nesting the new frontend under `packages/` (treating it as just another JS package) or leaving the backend unmoved at the repo root, we split the repo into three top-level roots: `backend/` (the existing FastAPI app, Alembic, tests, Dockerfiles), `frontend/` (the new Vite/React dashboard), and `packages/` (npm packages meant to be consumed by others, currently just the Playwright reporter). This keeps "things published for external use" (`packages/`) distinct from "the two halves of this one application" (`backend/`, `frontend/`), and avoids the backend looking like an implicit default at the repo root once a frontend exists alongside it.
